# sosd-报名作品集
##个人介绍
这个作品集是我（大一）开学后经历一个月的探索过程。
期间我尝试了可编程网络实验室的中秋挑战任务，因为设备问题我没有成功跑通一次SGLang模型。
    但这个过程我经历了第一次搭建环境，读论文，接触终端，命令行，创建Github账号，了解一些让AI快起来的方法，虽然抽象，还在努力理解，但这些过程比单纯跑通还有价值。
我也尝试sosd招新群里的AI-NLP文件，成功搭建pytorch环境，相对精读了attention这篇论文，还在理解当中。
